## 主题简介

很多人第一次接触 Agent Skill 都会觉得"这不就是把 prompt 存起来吗？"搞清楚之后你会发现，它其实是 AI Agent 时代非常重要的一种**能力封装方式**。

本文从概念、用法、原理到边界，把 Agent Skill 一次讲清。

## 核心观点

**Skill 的本质不是"更高级的提示词"，而是面向 Agent 的能力封装。**

它的核心价值不是"让模型多知道一点"，而是把重复方法论、固定流程、组织知识和执行入口，封装成一个 AI 可以反复调用的标准化能力。

### 四个概念的关系

| 概念 | 类比 |
|------|------|
| Prompt | 临时口头交代一句话 |
| Skill | 给新同事的一份岗位 SOP |
| MCP | 把同事接入 ERP / CRM / 数据库 / 工单系统 |
| Subagent | 再配几个分工明确的专业助手 |

## 关键概念速查

| 概念 | 说明 |
|------|------|
| **渐进式披露** | 元数据层（始终加载）→ 指令层（按需加载）→ 资源层（按需中的按需加载） |
| **Reference 的本质** | 读 —— 内容进入上下文，消耗 Token |
| **Script 的本质** | 跑 —— 执行脚本，利用结果继续任务，逻辑不进上下文 |
| **MCP vs Skill** | MCP 负责连接世界，Skill 负责教会 Agent 如何行动 |
