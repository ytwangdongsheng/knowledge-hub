## 主题简介

Harness Engineering 是 2025 年初 AI 圈兴起的新概念，核心思想是：围绕大模型搭建一套系统，让模型能够稳定、可靠地为人类做事。

本笔记覆盖：
- 从 Prompt Engineering 到 Context Engineering 到 Harness Engineering 的演进
- Harness 的核心公式：Agent = Model + Harness
- OpenAI 的实战案例：5 个月写 100 万行代码
- Anthropic 的三 agent 架构：planner、generator、evaluator
- 争议讨论：Harness Engineering 是不是噱头？
