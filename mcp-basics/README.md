## 主题简介

MCP（Model Context Protocol，模型上下文协议）是 Anthropic 于 2024 年 11 月发布的一个开放协议，让大模型能够使用各类外部工具。

本笔记覆盖：
- MCP 的核心概念（Host / Server / Tool）
- 安装与配置 MCP Host（以 Cline 为例）
- 配置 API Key（OpenRouter）
- 手动配置 MCP Server（JSON 文件）
- MCP 交互流程详解
- 使用他人的 MCP Server（uvx / npx）
